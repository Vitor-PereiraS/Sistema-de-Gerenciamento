# Projeto Prático — Sistema de Gerenciamento

## 1. Descrição

Este projeto consiste no desenvolvimento de uma aplicação web para gerenciamento de vendedores, departamentos e documentos, utilizando Java e tecnologias do ecossistema Java EE.

O objetivo foi aplicar na prática os conceitos de persistência de dados com **JPA e Hibernate**, integrados ao **JSF e PrimeFaces** para a construção das interfaces gráficas.

A aplicação permite realizar operações de CRUD (*Create, Read, Update e Delete*), possibilitando cadastrar, consultar, editar e excluir registros por meio de telas com funcionalidades básicas de gerenciamento.

O projeto foi desenvolvido com o propósito de consolidar conhecimentos em desenvolvimento web Java, integração com banco de dados, mapeamento objeto-relacional (ORM) e construção de interfaces utilizando componentes reutilizáveis.

## 2. Funcionalidades desenvolvidas

### Vendedores
- Listagem de vendedores em tabela paginada.
- Cadastro de novos vendedores.
- Edição de vendedores existentes.
- Exclusão de registros.
- Consulta de vendedores cadastrados.

### Departamentos
- Listagem de departamentos cadastrados.
- Cadastro de novos departamentos.
- Edição de departamentos existentes.
- Exclusão de registros.
- Consulta de departamentos.

### Documentos
- Gerenciamento de documentos cadastrados.
- Operações de cadastro, consulta, edição e exclusão (CRUD).

## 3. Tecnologias utilizadas

- **Linguagem:** Java.
- **Persistência de dados:** JPA e Hibernate.
- **Interface web:** JSF e PrimeFaces.
- **Banco de dados:** Oracle JDBC.
- **Servidor de aplicação:** WildFly.
- **Gerenciamento de dependências e build:** Maven.
- **Ambiente de desenvolvimento:** Eclipse IDE.
